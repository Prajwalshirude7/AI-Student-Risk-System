About the System & Architectural Specification

B.Tech Second-Year Mini-Project Integrating Data Structures & Algorithms, Machine Learning, Database Management, and Web Development.

Project Overview

The AI-Based Student Performance & Risk Prediction System is an integrated educational intelligence portal developed to detect student scholastic vulnerability at an early stage. By blending classical Data Structures and Algorithms with Supervised Machine Learning and Persistent Database Engineering, the application equips academic mentors with real-time diagnostic insights and non-judgmental, actionable recommendations.

Mandatory College Data Structure Implementations
Custom Hash Table

Implemented with polynomial rolling hash, bucket separate chaining, and dynamic capacity doubling at load factor 0.75.

Lookup Complexity: O(1) avg
Binary Search Tree (BST)

Indexes student academic performance scores, enabling sorted In-order traversal and O(K + log N) Range Search.

Search Complexity: O(log N) avg
Stack (LIFO)

Records mutation snapshots (CREATE, UPDATE, DELETE) and powers the functional Undo Last Action feature.

Push / Pop: O(1)
Queue (FIFO)

Buffers incoming student prediction tasks in arrival sequence for deterministic batch processing.

Enqueue / Dequeue: O(1)
Singly Linked List

Implements dynamic memory allocation with sequential node pointers for dynamic student chains without fixed allocation.

Head Insertion: O(1)
Array Operations

Provides custom divide-and-conquer QuickSort, multi-field filtering, and O(log N) Binary Search on contiguous student arrays.

Sort Complexity: O(N log N)
Machine Learning Pipeline
  • Model Architecture: Scikit-learn DecisionTreeClassifier configured with maximum depth 6 to ensure interpretability and minimize overfitting.
  • Features: Attendance (%), Internal Assessment (/100), Assignment Marks (/100), Previous Academic % (/100), Study Hours (hrs/day), Backlogs (integer).
  • Evaluation Methodology: Stratified 80/20 Train-Test split, preventing target label distribution skew and eliminating data leakage.
  • Target Classes: Low Risk, Medium Risk, High Risk.
